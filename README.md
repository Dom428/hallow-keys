# Hallow Keys

A personal password manager for Windows - part of the Hallow family with [Hallow Hub](https://github.com/Dom428/hallow-hub), [Hallow Mixer](https://github.com/Dom428/hallow-mixer), [Hallow Remote](https://github.com/Dom428/hallow-remote) and the others. Everything stays on your PC, in one encrypted file.

> Hallow Keys hasn't been audited by security experts. Keep using a tried-and-tested password manager for anything important, and keep backups.
